بيت البُن — النسخة النظيفة النهائية (Node.js + Neon PostgreSQL + Render)
=====================================================================

هذه النسخة كاملة. لا تحتاجين دمج أي ملفات من ZIP آخر.

قبل حذف المشروع القديم:
- احتفظي بملف .env القديم أو على الأقل قيمة DATABASE_URL الخاصة بـ Neon في مكان آمن.
- لا ترفعي .env إلى GitHub ولا ترسليه لأي شخص.

تشغيل المشروع محليًا على Windows:

1) افتحي هذا الفولدر نفسه في VS Code.
2) افتحي Terminal داخل VS Code.
3) شغّلي:

   npm install

4) لو ملف .env غير موجود، شغّلي:

   Copy-Item .env.example .env

5) افتحي .env واكتبي:

   PORT=3000
   HOST=0.0.0.0
   DATABASE_URL=هنا Neon connection string
   ADMIN_USER=admin
   ADMIN_PASSWORD=اكتبي باسورد قوي

6) شغّلي:

   npm start

7) افتحي الموقع:

   http://127.0.0.1:3000

8) لوحة الإدارة:

   http://127.0.0.1:3000/admin

9) اختبار سريع:
- اعملي Order من الموقع.
- افتحي /admin وتحققي أن الطلب ظهر.
- جرّبي Contact وNewsletter.

Render:
- Service type: Web Service
- Build Command: npm install
- Start Command: node server.js
- Instance: Free
- Environment Variables المطلوبة:
  DATABASE_URL = Neon connection string
  ADMIN_USER = اسم مستخدم الإدارة
  ADMIN_PASSWORD = باسورد قوي

لا تضيفي PORT في Render؛ Render يوفره تلقائيًا.

GitHub:
- .env متجاهل في .gitignore.
- بعد التأكد أن كل شيء يعمل، ارفعي النسخة الجديدة إلى نفس Repository.
